# LM Studio Codex v0.4.0

Reliability update for Windows, macOS and Linux.

- `lm-studio` now runs an exec-backed session loop. Follow-up messages resume the same conversation; `:new` starts fresh, `:exit` quits. `--tui` remains available.
- Model requests follow the single model currently loaded in LM Studio, including changes between tasks.
- Fix interrupted streams, CRLF parsing, parallel tool history, token accounting, hidden answers, Windows argument handling and Unix global command symlinks.
- Add explicit errors, request limits, progress messages, gateway version checks and ownership-safe process handling.
- Doctor tests a complete tool round trip and the actual Codex answer. Its default timeout is 300 seconds to accommodate cold prompt processing on local hardware.
- Optional `LMSTUDIO_CODEX_TRANSPORT=responses` uses LM Studio's native Responses endpoint. Chat translation remains the default.
- Retire the desktop-app experiment and disable unsupported cloud/multi-agent features in the local default profile.

## Install or Update

Extract the archive to a stable folder. Run `install/install.bat` on Windows or `bash install/install.sh` on macOS/Linux. Existing Git users can pull and rerun the installer. Node.js 22+, LM Studio and Codex CLI are required; automatic Codex installation uses tested version 0.160.0. Existing Codex versions are not replaced.

Keep LM Studio's OpenAI-compatible server enabled and load one chat/instruct model. Open a project terminal and run `lm-studio-doctor`, then `lm-studio`.

## Verification

23 local tests passed, including an installed Codex tool-execution and session-resumption test. GitHub CI also passed on Windows, macOS and Linux. Live Windows testing with the loaded Qwen 27B model passed streamed text, JSON, tool-result handling and a two-turn terminal session.

Cold Codex prompts can take minutes on local hardware even when a short chat response is fast. Progress messages distinguish waiting from silent exits. Model quality and hardware performance remain model-specific; this release does not guarantee every model or every future Codex version.
